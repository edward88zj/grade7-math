# 初一数学知识库 · 讲解与题库

人教版七年级数学（上册 + 下册）完整知识库：知识点讲解、公式速查、例题精讲、分层题库与逐题详解。

纯静态网页，**双击 `index.html` 即可离线使用**，无需安装、无需联网。

## 内容规模

| 项目 | 数量 |
| --- | --- |
| 章节 | 12 章（七年级上、下册全覆盖） |
| 知识点单元 | 37 个 |
| 精选题 | 223 道（基础 : 提高 : 拓展 ≈ 3 : 2 : 1） |
| 每题配备 | 2~4 步完整详解 + 易错点提示 |

**上册**：有理数 · 有理数的运算 · 代数式 · 整式的加减 · 一元一次方程 · 几何图形初步
**下册**：相交线与平行线 · 实数 · 平面直角坐标系 · 二元一次方程组 · 不等式与不等式组 · 数据的收集、整理与描述

## 每个单元的结构

1. **单元导读** —— 这节到底在解决什么问题
2. **知识点讲解** —— 3~5 个知识点，讲清「为什么」而不只是「是什么」，附易错标注
3. **公式 / 法则速查** —— 可直接背诵的卡片
4. **例题精讲** —— 典型题型分步拆解 + 易错提醒
5. **分层题库** —— 点击题目展开详解，再点收起

## 功能

- **全站搜索**：输入「绝对值」「一元一次方程」等关键词，跨章节命中知识点与题目，点结果直达对应单元并自动展开该题
- **连续导航**：首页章节卡片 → 章内小节 → 页尾「上一节 / 下一节」
- **学习进度**：已看过的题目标记保存在浏览器 localStorage，侧边栏显示「已看 / 总数」
- **响应式**：窄屏自动收起目录，手机上可正常使用

## 如何新增章节

1. 复制 `data/ch01.js`，改写为 `data/ch13.js`（或其他文件名）
2. 在 `index.html` 底部追加一行：`<script src="data/ch13.js"></script>`

数据格式：

```js
window.CHAPTERS = window.CHAPTERS || [];
window.CHAPTERS.push({
  id: "ch13", no: "十三", volume: "下册", title: "章节名", intro: "一句话简介",
  units: [{
    id: "u13-1", title: "13.1 小节名", diff: "★★☆", exam: "考点",
    summary: "单元导读，*强调* 语法会被渲染为加粗",
    points: [{ t: "知识点标题", d: "讲解", f: "公式（可选）", warn: "易错点（可选）" }],
    formulas: ["公式一", "公式二"],
    example: { q: "例题", steps: ["步骤一", "步骤二"], note: "易错提醒" },
    questions: [
      { diff: "基础", q: "题干", ans: ["步骤一", "步骤二"], tip: "易错点" }
    ]
  }]
});
```

> 注意：`diff` 只能取 `基础` / `提高` / `拓展`；数据文件内的字符串请使用中文引号「“”」，不要使用 ASCII 双引号，否则会破坏 JS 语法。
